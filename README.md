# INF.03 Exam Practice Repository
## Overview
This repository contains practice materials and solutions for the INF.03 professional qualification exam in IT. The exam focuses on creating and administering websites and web applications.

## Key Topics Covered
- HTML5 & CSS3
- JavaScript
- PHP & MySQL
- Web application development
